🏗 Architecture Strategy

High-availability multi-tenant design with strict data isolation and edge-first synchronization.

Multi-Tenancy Engine

The platform uses Logical Isolation via a global schoolId scope. Every query is automatically scoped to the user's tenant.

  • ● Isolated File Storage: /uploads/schools/{schoolId}/*
  • ● Tenant-Specific Enums: Custom assessment types and grading scales per school.
  • ● Subscription Gating: Features dynamically enabled based on PlanTier.
  • ● Platform Override: Super Admin role bypasses schoolId filters.

Data Lifecycle

1
Edge Interaction — PWA captures data even when offline
2
IndexedDB Persistence — Changes queued in Dexie sync table
3
Background Sync — Automatic retry when network is restored
4
Server Validation — Prisma enforces schema and role constraints

📡 Offline Support (Edge-First)

Optimized for environments with intermittent connectivity. Essential for high-traffic operations like attendance and grading.

Attendance Edge

Teachers can take attendance in classrooms without Wi-Fi. Records are stored in OfflineAttendance table in browser and synced later.

Student Data Cache

Core student profiles and class lists are cached locally (CachedStudent) for instant lookups even when the API is unreachable.

Conflict Resolution

Built-in ConflictRecord system handles "Last Write Wins" or "Manual Review" when multiple devices update the same record offline.

Developer Note: Offline logic is encapsulated in frontend/src/lib/db/sync-service.ts. It manages the SyncQueueItem lifecycle (Pending → In Progress → Completed/Failed).

🇪🇹 Ethiopian Localizations

Deep integration with Ethiopian academic standards and cultural requirements.

Dual Calendar Engine

The system supports simultaneous Gregorian and Ethiopian (Ge'ez) calendars. Schools can set calendarType: ETHIOPIAN in their settings.

  • ● Automatic Conversion: Dates stored as UTC in DB, displayed in ET format.
  • ● ET Academic Years: Support for 13 months and ET year numbers.
  • ● Holiday Integration: Pre-configured Ethiopian public holidays.

MoE Syllabus Mapping

Alignment with Ethiopian Ministry of Education curriculum requirements via SyllabusMapping model.

📈 Academic & Grading System

Flexible grading architecture supporting diverse curriculum types and assessment methods.

Dynamic Grading Components

Unlike rigid systems, SMS allows schools to define their own GradingComponent sets (e.g., CA 10%, Mid 30%, Lab 10%, Final 50%).

Grading Approval Workflow: Teacher Entry (Draft) → Registrar Review (Pending) → Admin/Registrar Approval (Locked). Once approved, GradeChangeLog tracks any subsequent edits for audit trails.

  • ● Score Filters: Exclude students who haven't met attendance/fee requirements.

🛡 Backend Guards Registry

Hierarchical security enforcement for every incoming request.

1. JwtAuthGuard

Extracts and validates identity from the Authorization header.

2. RolesGuard

Validates the Role enum against the @Roles() decorator metadata.

3. PermissionsGuard

Checks granular Permission records and enforces schoolId isolation.

4. SubscriptionGuard

Ensures the current tenant's PlanTier supports the requested module.

5. RateLimitGuard

Throttles requests to prevent DoS attacks on critical endpoints like /auth/login.
