# Inventory Module

> Purpose: School asset and inventory management.

---

## Status: ❌ Not Started (planned for v1.0)

## Proposed Responsibilities
- Asset tracking (furniture, computers, lab equipment)
- Stock management (consumables)
- Asset assignment and location tracking
- Maintenance scheduling
- Inventory reporting

## Proposed Features
- Asset registration with serial numbers
- Stock in/out tracking
- Asset assignment to departments/classrooms
- Maintenance schedule and history
- Inventory valuation reports
- QR code asset tagging
