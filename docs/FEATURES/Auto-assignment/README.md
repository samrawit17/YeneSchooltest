# Auto-Assignment Module

> Purpose: Automatic assignment of teachers, students, and resources.

---

## Responsibilities
- Auto-assign teachers to classes/subjects
- Auto-assign students to sections
- Batch assignment operations
- Assignment validation and conflict detection

## Features
- Teacher workload balancing
- Student section assignment (alphabetical, random, balanced)
- Class-teacher-subject auto-matching
- Assignment reports and validation

## Permissions
- `ADMIN`: Configure and run auto-assignment
